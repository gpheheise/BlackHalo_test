    Disclosure index

    Open a disclosure to read its writeup, loaded from the linked GitHub repository, with the CVSS breakdown and links to the proof of concept and NVD.

    One repository per disclosure

    Research on GitHub

    Each disclosure has its own public repository. Its README is the writeup shown on this site, and its poc/ folder holds the proof of concept.

    gpheheise/CVE-2026-48210 ├── README.md # writeup, rendered on this site ├── poc/ │ ├── README.md # setup and expected result │ └── exploit.py └── LICENSE

    Writeups are fetched from the repository when you open a disclosure, so fixing a typo on GitHub updates this site without a redeploy.

    Coordinated disclosure

    From finding to publication

    Nothing appears here before the vendor has had the chance to fix it.

    1. 01

      Discover

      The agent engine maps attack surface and chains primitives across real targets.

    2. 02

      Validate

      A researcher reproduces and triages every candidate before it is counted.

    3. 03

      Notify

      The vendor is contacted privately with details and a proof of concept.

    4. 04

      Remediate

      A 90-day window, extended in good faith while a fix is in progress.

    5. 05

      Publish

      CVE, writeup and minimal PoC go public once a fix ships or the deadline passes.
